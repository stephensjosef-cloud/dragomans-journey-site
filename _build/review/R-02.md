### N1. LOSES CUSTOMERS · The monthly support fee reads as required, and nothing on the way to the sale says otherwise
- **Pages, width:** local.html and sample-blueprint.html at 390.
- **What a person sees:** Local's busywork card says "Build from $3,000 · support from $750/month". ## Differed from this plan

- **The build check needed three runs.** In the first, the clone used this machine's `core.autocrlf=true`, so the checkout itself had CRLF. In the second (`core.autocrlf=false`), Python on Windows still wrote CRLF: 50 of 75 files matched byte for byte, and all 75 matched once CRLF became LF. The third run, reported above (75/75), used a `sitecustomize.py` in a scratch folder, loaded through `PYTHONPATH`, that makes Python's text-mode writes use LF. No repo file was touched. Future build jobs on this Windows workspace need the same, or WSL or Linux.
- **One command was chained:** early on, `cd <repo> && git remote -v` ran as one call, against the rule. It only read the remote. Every later command ran on its own.
- **Branch in the existing clone:** `review/R-02` was made in the existing local clone, which was on `trip/T-46` with untracked build folders. They were left untouched, and the clone is left on `review/R-02`.
- **Extra screenshots:** besides the top of each page at 390 and 1440, the commit has the header crops (`hdr-*`) and evidence screenshots (`ev-*`) that findings cite.
- **Extra header widths:** 759, 760 and 761 were also measured around the 760 breakpoint, and the home page alongside.
- **A false alarm ruled out:** while running the receipt, a page error "Cannot set properties of null (setting 'href')" appeared. It was caused by the test script renaming the receipt's `#bring` link to hit-test it. A clean run with the same steps gives no error, so it is not a finding.
- **Reviewers' claims were checked** against the pages before they counted (both briefs were followed as written).
